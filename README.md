# 11 買い物メモアプリ

このアプリは、日頃の買い物や欲しい物をメモしておくためのシンプルな買い物リストです。Streamlit の `session_state` でリストを管理するため、ページを更新してもデータが保持されます。

## 機能

- アイテム名を入力してリストに追加
- 複数のアイテムを選択してまとめて削除
- リストをワンクリックで全てクリア
- 登録されたアイテムを順番付きで表示

## 使い方

1. コマンドラインで以下を実行してアプリを起動します。

   ```bash
   streamlit run app.py
   ```

2. テキスト入力欄に買う予定のアイテム名を入力し、**「追加」**ボタンを押すとリストに追加されます。

3. **「削除したいアイテムを選択してください」**のプルダウンから削除したいアイテムを選択し、**「選択したアイテムを削除」**ボタンを押すと選択したアイテムが削除されます。

4. リスト全体を空にしたい場合は、**「リストを全てクリア」**ボタンを押します。

このアプリは、Streamlit での基本的な状態管理やリスト操作の学習に最適です。
