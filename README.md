# 11 買い物メモアプリ

このアプリは、日頃の買い物や欲しい物をブラウザ上でメモしておくためのシンプルな買い物リストです。Streamlit のセッション状態には依存せず、クライアント側（ブラウザ）の JavaScript でリストを管理しています。そのため、ボタン操作が即座に反映され、`session_state` がうまく更新されない環境でも安定して動作します。

## 機能

- アイテム名を入力してリストに追加
- 「リストを全てクリア」ボタンでリストを一度に空にする
- 登録されたアイテムを順番付きで表示

## 使い方

1. コマンドラインで以下を実行してアプリを起動します。

   ```bash
   streamlit run app.py
   ```

2. テキスト入力欄に買う予定のアイテム名を入力し、**「追加」**ボタンを押すとリストに追加されます。

3. リスト全体を空にしたい場合は、**「リストを全てクリア」**ボタンを押します。

このアプリは、Streamlit とブラウザ内 JavaScript を組み合わせた簡単なアプリケーション開発の例としてご活用いただけます。サーバーサイドのセッション状態を使わないため、動作環境による違いが少ない構成になっています。
